# 余白

スマートフォン向けの一日予定・Todo管理アプリです。

## 起動

- ローカルでは、ブラウザで index.html を開きます。
- GitHub Pages では、公開元に設定したブランチの公開フォルダ内にこのディレクトリを置き、公開 URL の /tomorrow/ を開きます。ディレクトリの中身を公開ルートに置く場合は、公開 URL のルートで開けます。ビルドは不要です。

予定、Todo、よく使う項目はブラウザの localStorage に保存します。保存データはブラウザと公開元ごとに分かれます。

Home の上部から翌日の予定を追加・編集できます。24時間の時計では、保存済みの予定と入力中の時間帯を確認できます。予定の重複と日付をまたぐ入力は受け付けません。Todo は当日分を独立して管理します。
